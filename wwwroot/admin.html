Componentes Integrados en la Solución Enterprise

Este sistema implementa una arquitectura cloud con servicios de Microsoft Azure alineados a los principios éticos de Inteligencia Artificial Responsable:

  • Motor Backend: ASP.NET Core (.NET 10 Minimal APIs) en servidor Kestrel ultra-optimizado (~35 MB RAM).
  • Inteligencia Artificial: Microsoft AI Foundry Agent con RAG vectorial sobre 5 reglamentos oficiales de la institución. Respuestas concisas y directas.
  • Servicios de Voz (Inclusión): Azure AI Speech (Speech-to-Text) y Web Speech API nativa para interacción por micrófono (🎙️) sin teclear.
  • Persistencia y Gobernanza (Rendición de Cuentas): Base de datos relacional híbrida (PostgreSQL Flexible Server PaaS / SQLite) para registro de auditoría y métricas de satisfacción estudiantil (👍/👎).
  • Seguridad Zero-Secrets: Autenticación RBAC mediante Microsoft Entra ID y Managed Identity.
